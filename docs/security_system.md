# 🛡️ 地瓜派 RDK X5 多模态智能空间安防与智能门禁系统设计方案

> **项目定位**：基于地平线 RDK X5 边缘 AI 芯片平台的工业级软硬件融合安防中枢。  
> **核心融合栈**：激光雷达主动空间测距 + 10 TOPS BPU 硬件加速视觉推理 + InsightFace 512维深度人脸识别（带 2D 姿态偏航角过滤） + ML-FPM007 面阵半导体指纹 + 360° 连续旋转伺服齿条自适应门禁（断电位置记忆） + TI ADS1115 16位高精度声学破拆感知 + AHT10 微气象温湿度火警 + FastAPI / WebSocket 10Hz 全双工 Web 态势感知大屏。

## 三、核心算法与系统机制

### 3.1 工业级人脸识别与 2D 姿态偏角过滤 (`face_recognition.py`)

传统 1:N 人脸识别在门禁实际落地时，最容易因人员歪头、行走抓拍侧脸或摄像头倾角导致特征提取失真，造成误比对开门。本项目创新性地设计了基于 5 点人脸关键点的 **2D 姿态偏航角估计与侧脸拦截算法**：

1. **双眼连线 Roll 旋转校正**：  
   根据人脸检测模型输出的左眼坐标 $(x_{\text{le}}, y_{\text{le}})$ 与右眼坐标 $(x_{\text{re}}, y_{\text{re}})$，计算倾角并进行 2D 逆旋转变换：
   $$\theta = \arctan2(y_{\text{re}} - y_{\text{le}}, x_{\text{re}} - x_{\text{le}})$$
   消除人员歪头及摄像头物理安装倾斜带来的几何投影变形。
2. **归一化水平偏航角（Yaw）估算**：  
   计算旋转对齐后鼻尖点相对于双眼几何中心在水平轴的偏离比例：
   $$\text{offset} = \frac{x'_{\text{nose}} - x'_{\text{mid}}}{x'_{\text{re}} - x'_{\text{mid}}}, \quad \text{Yaw} = \text{clip}(\text{offset} \times 45.0^\circ, -60^\circ, 60^\circ)$$
3. **动态侧脸过滤机制**：  
   - 默认采用工业门禁标准阈值 **$|\text{Yaw}| \le 35.0^\circ$**；
   - 侧脸超标时立即拦截：不提取 512 维深度特征、不比对、不开门，画面标注黄框提示“请正对摄像头”；
   - 仅当正脸相似度 $\ge 0.450$ 且门禁处于静止关闭状态时，方可拉起自动开门动作并自动抓拍存底。

### 3.2 地平线 10 TOPS BPU YOLOv8 硬件加速检测 (`bpu_detection.py`)

- **BPU 异构推理**：将 YOLOv8 目标检测模型深度编译为地平线专有的 `.bin` 硬件模型（`yolov8n_640x640_nv12.bin`），由 RDK X5 内置的高能效 BPU 协处理器以 NV12 格式直接推理；
- **极速性能**：单帧端到端推理耗时稳定在 **$15 \sim 25\text{ ms}$**，CPU 占用率接近 $0\%$；
- **智能人/物分离**：实时将视野中的行人、宠物、车辆、移动包裹等目标解耦；当激光雷达检测到防区存在侵入时，协同视觉 BPU 确认是否为人类活动，杜绝小动物引发误警。

### 3.3 ML-FPM007 面阵半导体指纹模组驱动 (`fingerprint_manager.py`)

- **严格对齐小端序协议**：通信采用 UART1 (9600 bps, 8-N-1)，帧头为小端字节序 `EF 02`，数据包覆盖 `CRC16-XMODEM` 动态校验；
- **低功耗中断唤醒**：平时模组可进入微安级休眠（`0x0390`），监听 Pin 11 (BCM 17) TOUCH 引脚，手指贴附即时触发高电平中断唤醒系统；
- **高可靠两步验证时序**：严格遵循厂家 V3 硬件时序（`0x0325` 采图入片上缓存 $\rightarrow$ `0x0328` 模组 1:N 特征检索），比对耗时 $\le 300\text{ms}$；
- **3 次按压采集合成录入**：录入指纹时分 3 步采集手指不同角度特征，中间自动检测手指抬起状态（`0x0336`），最后在模组 Flash 中融合为高容错模板（`0x0327`）。

### 3.4 激光雷达防区空间聚类与自适应背景差分 (`detector.py`)

- **跨 0° 闭环防区几何判定**：支持正前方跨越 $0^\circ / 360^\circ$ 轴的任意扇形与矩形警戒区域，消除传统极坐标运算符在轴线断裂的感知死角；
- **欧氏距离空间聚类（Euclidean Clustering）**：相邻反射点距离小于 $18\text{ cm}$ 且连通点数 $\ge 3$ 时方聚类为实体目标，彻底过滤扬尘、飞虫等离散单点噪声；
- **3 秒自适应静态背景差分**：系统标定时自动采集 3 秒环境静态墙体轮廓基线（360° 最远距离包络），入侵检测时自动滤除固定静止障碍物。

### 3.5 360° 伺服舵机自适应齿条门禁（断电记忆） (`actuators.py`)

- **虚拟绝对编码器**：针对无角度电位器反馈的 360° 连续旋转开环舵机，采用毫秒级时间微积分模型实时跟踪门禁开度（$0.0 \sim 1.0$）；
- **残余运转时间自适应补偿**：在门禁运动中途接收到急停或反向指令时，动态计算剩余所需运转时间，杜绝机械过冲打齿；
- **断电位置持久化**：门禁动作完成或校准后，实时将开度落盘至 `config.json`，板端断电重启后零点记忆不丢步。

### 3.6 车规声学破拆与微气象火警监测

- **ADS1115 声学破拆检测**：16 位高精度 ADC 差分采样驻极体麦克风信号，动态跟踪环境基线直流偏置（$\alpha=0.05$），检测机械撬锁或踢门的瞬态冲击波峰峰值（$\ge 80\text{mV}$），$30\text{ms}$ 内触发警报；
- **AHT10 微气象火警**：实时监测环境温湿度，突破门限（默认 $45^\circ\text{C}$，支持 $30\sim 70^\circ\text{C}$ 动态配置）时 $1\text{s}$ 内拉响声光报警，OLED 屏幕弹出反色警报。

## 五、Web 态势感知综合大屏

系统后端采用 FastAPI 构建异步高并发 REST API，并通过 WebSocket 以 10Hz 频率向下游推送雷达点云坐标、三级警戒状态、门禁开度、环境温湿度与声音分贝值。前端为自研现代化单页应用（SPA）：

- **Tab 1 · 综合态势大屏**：雷达极坐标画布、双路视频流画中画（HUD 目标框实时叠加）、三级声光状态指示灯；
- **Tab 2 · 实时视频监控**：主摄全景与人脸特写双路独立推流，支持手动调节曝光增益；
- **Tab 3 · 防区与雷达标定**：交互式拖拽设置预警防区（WARNING）与报警防区（ALARM），一键背景轮廓自学习；
- **Tab 4 · 人脸识别底库**：实时注册人脸底库、查看人员工号与特征向量、配置开门置信度阈值与侧脸拦截开关；
- **Tab 5 · 指纹门禁管理**：指纹状态诊断、3 次向导式录入添加、指纹清空与触碰测试；
- **Tab 6 · 审计日志与存证**：FIFO 50 张自动抓拍相册实时预览、多维度告警事件日志查询与 CSV 报表导出。
