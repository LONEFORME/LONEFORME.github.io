1. 赛场环境离散拓扑图建模 ​

参考源码：01_锡月无人机实战系统/02_树莓派机载主控/自启动/path_generator.py

在电赛 2025-H 题（野生动物巡查）等赛题中，比赛场地通常为 450cm×350cm 的矩形区域。若直接在连续空间规划轨迹，不仅解算复杂度极高，且易因累积误差偏离航线。工程上的标准解法是将连续空间离散化为网格拓扑图 G(V,E)：

1.1 网格参数与坐标映射 ​

  • 网格规格：水平 7 列 × 纵向 9 行，共 63 个单元格；
  • 单元格物理尺寸：每个单元格中心点间距约为 ΔX=50cm,ΔY=50cm ，四周保留安全缓冲区；
  • 格号换算公式：设格号为 ID∈[1,63] ： Row=⌊(ID−1)/7⌋,Col=(ID−1)(mod7)Xworld=X0+Col⋅ΔX,Yworld=Y0+Row⋅ΔY

2. 全覆盖路径规划算法（DFS 蛇形扫描） ​

为确保巡查过程中不遗漏任何可能出现目标的单元格，且总飞行耗时最短，系统采用了改进型深度优先搜索（DFS）与蛇形往复往返遍历策略：

2.1 规划原则 ​

  1. 转向代价最小化：四轴无人机在拐弯减速、旋转机头时能量损耗最大；优先沿长轴方向做直线连续匀速巡航；
  2. 零回头路：维护已访问节点位图（Visited Bitmask），每个有效单元格仅途径一次；
  3. 巡航高度恒定：全流程保持巡航高度（如 Z=1.5m ），待相机检出目标后再执行降高与靶心对准。

3. 动态避障与重规划算法（Dijkstra） ​

在比赛现场，裁判会临时指定数个“禁飞区/火灾/障碍网格”（例如通过地面站蓝牙下发格号 [15, 23]）。无人机必须具备毫秒级局部动态绕行重规划能力：

text
[接收地面站下发的禁飞区格号]
              │
              ├── 在拓扑图 G(V, E) 中断开与禁飞格连接的全部邻接边 (Weight = ∞)
              ▼
[调用 Dijkstra 算法寻找绕障最短连通拓扑链]
              │
              ├── 剔除共线多余冗余点 (路径平滑与拐点提取)
              ▼
[生成全新 router.txt 航点序列] ──► 注入飞行控制状态机执行

3.1 核心算法实现细节 ​

  • 临界无解防护：若禁飞区将目标或通路完全封死，算法必须提前捕获异常并回退至上一安全悬停点，坚决避免死循环卡死；
  • 共线航点压缩：若连续三个路径点 (P1,P2,P3) 斜率相同，直接剔除中间过渡点 P2 ，直接将航点序列压至拐弯极值点，保证飞行姿态流畅、不频繁点刹顿挫。

4. 飞行任务有限状态机（FSM）开发架构 ​

参考源码：01_锡月/02_树莓派机载主控/自启动/A_fly_deal.py

整个全自主飞行流程绝不采用单线程 while(1) + time.sleep() 的初学者写法，而是构建严格的事件驱动型有限状态机（Finite State Machine）：

text
┌──────────────┐     按键触发模式选择 / 地面站起飞帧
│  1. IDLE     │ ──────────────────────────────────────► ┌──────────────┐
│  待机自检    │                                         │ 2. TAKEOFF   │
└──────────────┘                                         │ 垂直起飞定高 │
                                                         └──────┬───────┘
                                                                │ 达到定高 1.5m 且位姿收敛
                                                                ▼
┌──────────────┐     检出目标靶心 / 触发降落点          ┌──────────────┐
│ 4. DESCEND   │ ◄────────────────────────────────────── │ 3. NAVIGATE  │
│ 降高至0.5m对准│                                         │ 航点循迹巡航 │
└──────┬───────┘                                         └──────────────┘
       │ 水平位置偏差 < 3cm
       ▼

4.1 各状态职责与安全转移条件 ​

  1. IDLE（待机自检）：检查 T265 追踪置信度、飞控串口连通性与电池电压；双色 LED 红灯闪烁表示自检，绿灯长亮表示就绪；
  2. TAKEOFF（垂直起飞）：向飞控发送垂直上升速度指令，利用激光 ToF 实时监测高度；当 Z≥1.5m±5cm 且水平漂移 <3cm 持续 1 秒，无缝切入 NAVIGATE；
  3. NAVIGATE（航点循迹）：按行迭代 router.txt 中的航点；以当前实际坐标与目标坐标计算三维误差向量，并传入位置环控制器；若视觉线程检出同心圆或识别目标，立刻挂起巡航切入 DESCEND；
  4. DESCEND（阶梯降高）：一阶下降至安全观测高度（如 0.5m ），开启单目反投影闭环对准，消除下视对准误差；
  5. HOVER_WAIT（悬停确认）：在对准后的目标正上方保持零速度稳态悬停，触发声光报警/投放机构，并通过蓝牙回传播报；
  6. LAND（断电接地）：发送负垂直速度平稳接地；ToF 测得高度 <10cm 且持续下降率归零时，发送飞控加锁（Disarm）指令，彻底切断电机 PWM 输出。
