05 路径规划与自主决策 ​

本文档属于 全栈技术知识库。 涵盖赛场离散环境拓扑建模、DFS 9×7 全网格覆盖搜索、Dijkstra 动态绕障重规划算法以及飞行任务有限状态机（FSM）调度架构。

1. 赛场环境离散拓扑图建模 ​

参考源码：01_锡月无人机实战系统/02_树莓派机载主控/自启动/path_generator.py

在电赛 2025-H 题（野生动物巡查）等赛题中，比赛场地为 450cm × 350cm 的矩形区域（由 500cm × 400cm 喷绘布四周各留 25cm 边距形成），划分为 63 个 50cm × 50cm 方格。若直接在连续空间规划轨迹，不仅解算复杂度极高，且易因累积误差偏离航线。工程上的标准解法是将连续空间离散化为网格拓扑图 G(V, E)：

1.1 网格参数与坐标映射（与真题及工程代码一致） ​

  • 网格规格：横向 A1~A9 共 9 列（X 轴，长 450cm），纵向 B1~B7 共 7 行（Y 轴，宽 350cm），方格以代码 AnBm（如 A3B5）命名——与 2025 真题图 1 及 path_generator.py 的解析逻辑完全一致；
  • 单元格物理尺寸：相邻方格中心间距 50cm（ΔX = ΔY = 0.5m），四周保留安全缓冲区；
  • 世界坐标约定（锡月工程）：以起飞区 A9B1 为原点，与代码中 X = (A 序号 − 9) × 0.5m、Y = (B 序号 − 1) × 0.5m 的换算一致（A9 → X=0，B1 → Y=0）；
  • 禁飞区表达：真题禁飞区由若干连续方格构成（现场抽签给出方格代码，图 1 示例即 A3B3~A5B3 三个连续方格），规划器将其标记为不可通行节点。

2. 全覆盖路径规划算法（DFS 蛇形扫描） ​

为确保巡查过程中不遗漏任何可能出现目标的方格，且总飞行耗时最短，系统采用了改进型深度优先搜索（DFS）与蛇形往复往返遍历策略：

2.1 规划原则 ​

  1. 转向代价最小化：四轴无人机在拐弯减速、旋转机头时能量损耗最大；优先沿长轴方向（A1→A9，450cm）做直线连续匀速巡航；
  2. 零回头路：维护已访问节点位图（Visited Bitmap），除 DFS 回溯外每个有效方格仅途径一次；
  3. 巡航高度恒定：2025 真题要求巡查高度 120±10cm 且全程不得偏离航线，全流程保持定高，待相机检出目标后再执行降高与靶心对准。

3. 动态避障与重规划算法（Dijkstra） ​

在比赛现场，裁判会临时指定若干"禁飞方格代码"（如 A3B3, A4B3, A5B3）。无人机必须具备毫秒级局部动态绕行重规划能力（锡月工程实测解算耗时 < 50ms）：

[接收地面站下发的禁飞区方格代码]
              │
              ├── 在拓扑图 G(V, E) 中断开与禁飞格连接的全部邻接边 (Weight = ∞)
              ▼
[调用 Dijkstra 算法寻找绕障最短连通拓扑链]
              │
              ├── 剔除共线多余冗余点 (路径平滑与拐点提取)
              ▼

3.1 核心算法实现细节 ​

  • 临界无解防护：若禁飞区将目标或通路完全封死，算法必须提前捕获异常并回退至上一安全悬停点，坚决避免死循环卡死；
  • 共线航点压缩：若连续三个路径点 (P1, P2, P3) 斜率相同，直接剔除中间过渡点 P2，将航点序列压至拐弯极值点，保证飞行姿态流畅、不频繁点刹顿挫。

3.2 航线文件标准接口规范 ​

4. 飞行任务有限状态机（FSM）开发架构 ​

参考源码：01_锡月无人机实战系统/02_树莓派机载主控/自启动/A_fly_deal.py

整个全自主飞行流程绝不采用单线程 while(1) + time.sleep() 的初学者写法，而是构建严格的事件驱动型有限状态机（Finite State Machine）：

text
┌──────────────┐     按键触发模式选择 / 地面站起飞帧
│  1. IDLE     │ ──────────────────────────────────────► ┌──────────────┐
│  待机自检    │                                         │ 2. TAKEOFF   │
└──────────────┘                                         │ 垂直起飞定高 │
                                                         └──────┬───────┘
                                                                │ 达到定高且位姿收敛
                                                                ▼
┌──────────────┐     检出目标靶心 / 触发降落点          ┌──────────────┐
│ 4. DESCEND   │ ◄────────────────────────────────────── │ 3. NAVIGATE  │
│ 降高至0.5m对准│                                         │ 航点循迹巡航 │

4.1 各状态职责与安全转移条件 ​

  1. IDLE（待机自检）：检查 T265 追踪置信度、飞控串口连通性与电池电压；双色 LED 红灯闪烁表示自检，绿灯长亮表示就绪；
  2. TAKEOFF（垂直起飞）：向飞控发送垂直上升速度指令，利用激光 ToF 实时监测高度；当达到定高窗口（示例工程为 1.5m ± 5cm，赛题按 120±10cm 校验）且水平漂移 < 3cm 持续 1 秒，无缝切入 NAVIGATE；
  3. NAVIGATE（航点循迹）：按行迭代 router.txt 中的航点；以当前实际坐标与目标坐标计算三维误差向量，并传入位置环控制器；若视觉线程检出同心圆或识别目标，立刻挂起巡航切入 DESCEND；
  4. DESCEND（阶梯降高）：一阶下降至安全观测高度（如 0.5m），开启单目反投影闭环对准，消除下视对准误差；
  5. HOVER_WAIT（悬停确认）：在对准后的目标正上方保持零速度稳态悬停，触发声光报警/投放机构，并通过蓝牙回传播报；
  6. LAND（断电接地）：发送负垂直速度平稳接地；ToF 测得高度 < 10cm 且持续下降率归零时，发送飞控加锁（Disarm）指令，彻底切断电机 PWM 输出。
