1. 电赛机载视觉的三大恶劣挑战与抑制对策 ​

无人机机载相机在室内赛场运行时，与工业固定相机面临截然不同的恶劣光学环境：

挑战现象物理根因工程及格对策（必须固化在驱动层）
画面明暗横条纹滚屏（频闪）室内赛场多采用 50Hz 工频荧光灯或 LED 灯，相机自动曝光时间与灯光交流波峰不匹配强制锁定曝光（禁用 AE）：在相机初始化代码中关闭自动曝光，将曝光时间强制定为 1/100s（10ms）或其整数倍，彻底消除频闪滚屏。
高速飞行边缘拖影（运动模糊）曝光时间过长叠加无人机快速机动提升增益（Gain）并压低曝光：以适度牺牲画质噪点为代价，将单帧曝光压缩至 2~5ms 以内，确保边缘锐利。
地毯与环境漫反射色差场地不同位置的光照不均匀，阴影区与高光区 HSV 严重偏移双色彩空间联合判定：结合 HSV 空间的色调（H）与 BGR 空间的色彩通道比例差，动态放宽光照分量（V）的门限。

2.2 几何轮廓多边形逼近（cv2.approxPolyDP） ​

利用道格拉斯-普克（Douglas-Peucker）算法对二值化轮廓曲线进行多边形拟合：

  • 逼近精度：ε = 0.02 × 周长（Perimeter）；
  • 顶点数分类：
    • N = 3：严格判定为三角形；
    • N = 4：计算宽高比 Aspect Ratio = W / H，接近 1.0 为正方形，偏离 1.0 为长方形；
    • N = 5：判定为五边形；
    • N > 6：进入圆形度判定逻辑。

2.3 起降同心圆（靶标）严格判据 ​

电赛起降靶心通常为“黑白相间”或“红白相间”的同心圆环，判定必须满足两大数学约束：

  1. 圆形度判据（Circularity）： 圆度判据 C = 4πA / P² ≥ 0.80 ~ 0.85 （理论上纯圆为 1.0，方块等几何体通常 < 0.78）；
  2. 内外轮廓拓扑层级（Hierarchy）： 通过 cv2.findContours(..., cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE) 构建拓扑层级树，检验外层圆轮廓是否包含恰好一个内层子轮廓，且两个轮廓的外接圆心欧氏距离 < 5 像素，内外圆半径比例符合预设模具尺寸。

3.1 物理反投影数学推导 ​

设相机主点为 (cx, cy)，标定焦距为 fx、fy，机载 ToF 测得的当前离地净高为 Z： ΔX_body = Z·(u - cx) / fx ，ΔY_body = Z·(v - cy) / fy

3.2 速度前馈比例收敛控制 ​

为避免到达目标上方时姿态剧烈超调造成震荡，采用比例速度控制引导对准： V_x = clamp(Kp · ΔX_body, -V_max, V_max) V_y = clamp(Kp · ΔY_body, -V_max, V_max)

  • 降落切换阈值：当水平综合误差 √(ΔX² + ΔY²) < 3cm 且持续保持 0.5 秒以上，状态机自动切入 DESCEND 降落停机阶段。

4. 官方底层视频流与广播握手真源（OpenVision.py） ​

参考源码：01_锡月无人机实战系统/04_视觉识别/OpenVision.py

在机载上位机向地面端传输画面时，传统的 TCP 连接在飞行抖动丢包时会产生灾难性的“帧堆积与秒级延迟”。本工作区找回的失传真源 OpenVision.py 采用了专为无人机优化的通信机制：

  1. UDP 无阻塞流式传输：
    • 采用无连接的 UDP 套接字，单帧图像经 JPEG 压缩后分片直发；即使偶遇无线丢包，下一帧到达瞬间立刻覆盖显示，端到端延迟控制在 30ms 以内；
  2. 局域网自动广播发现（Zero-Config）：
    • 编写了 find_ground_station_ip() 函数，机载端通过向 255.255.255.255:6055 发送 DRONE_DISCOVERY_REQUEST 广播包；
    • 地面站监听到后自动回传 IP 地址，机载端瞬间锁定目标，彻底告别比赛现场切换路由器后手动登机改 IP 的麻烦。
