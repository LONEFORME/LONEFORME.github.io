## 1. 室内无 GPS 厘米级定位核心挑战

在电赛室内密闭赛场中，无人机无法使用卫星 GPS/北斗定位；而传统的单点光流受限于地面反光与低纹理特征，气压计受困于空气动力学风浪扰动。要实现自主穿框、定点悬停与全网格覆盖，必须依赖**机载高频双目视觉惯性里程计（VIO）**与**激光测距雷达**的深度融合。

## 2. Intel RealSense T265 双目 VIO 坐标系空间几何变换

T265 内部集成了两颗广角鱼眼单色相机和一颗 Bosch BMI055 惯导传感器，由内部 Movidius VPU 以 200Hz 独立解算机体 6 自由度位姿。

```text
[T265 相机原生坐标系] ──► (四元数转欧拉角) ──► [机载机体坐标系 (Body)] ──► (旋转矩阵正投影) ──► [大地世界坐标系 (NED)]
```

### 2.1 四元数转航空欧拉角数学模型
参考代码：`01_锡月无人机实战系统/02_树莓派机载主控/自启动/A_DataDeal.py`

设 T265 驱动输出的姿态四元数为单位四元数 q = (w, x, y, z)：
1. **滚转角（Roll φ）**：
   Roll = arctan2( 2(wy + xz), 1 - 2(x² + y²) )
2. **俯仰角（Pitch θ）**：
   Pitch = arcsin( clamp( 2(wx - yz), -1, 1 ) )
3. **偏航角（Yaw ψ）**：
   Yaw = arctan2( 2(wz + xy), 1 - 2(x² + z²) )

### 2.2 大地世界坐标系（NED 东北天）映射
由于 T265 通常前向斜下或平直安装在无人机头部，传感器坐标系与飞控大地坐标系存在固定的安装外参偏差 (X_offset, Y_offset, Z_offset) 与对齐角度 α：
$$\begin{bmatrix} X_{\text{world}} \\ Y_{\text{world}} \\ Z_{\text{world}} \end{bmatrix} = \begin{bmatrix} \cos\psi_0 & -\sin\psi_0 & 0 \\ \sin\psi_0 & \cos\psi_0 & 0 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} X_{\text{t265}} \\ Y_{\text{t265}} \\ Z_{\text{t265}} \end{bmatrix} + \begin{bmatrix} X_{\text{offset}} \\ Y_{\text{offset}} \\ Z_{\text{offset}} \end{bmatrix}$$
* 在起飞解锁瞬间记录初始偏航角 ψ₀，后续所有航点循迹均以此大地坐标系为基准，消除累积发散。

### 2.3 T265 硬件看门狗自愈机制
参考代码：`02_凌霄飞控与空地协同/自研系统/部署/watchdog/t265_monitor.py`
* **痛点**：长时间运行或受到强烈电磁干扰时，T265 的追踪置信度（Tracker Confidence）可能突然跌至 0，甚至断开连接；
* **看门狗策略**：
  1. 周期性（每 1 秒）检测设备状态与置信度；
  2. 若检测到设备脱机或置信度连续 3 秒为 0，看门狗自动执行 `usbreset 03e7:2150` 并重启位姿服务；
  3. 通过 I2C 在机载 OLED 上实时显示 `T265: READY`、`NEED REPLUG` 或 `TRACKING LOSS` 警报。

## 3. 2D 激光雷达极速避障与立柱追踪（免 ROS 纯 Python）

在电赛 2020-D 题（绕障飞行器）以及 2026-D 题等复杂场景中，赛场布设了多根细立柱（直径 Φ ≤ 2cm），机载重量与算力不允许运行庞大的 ROS 节点。

在本地工程 `03_激光雷达SLAM避障/2d激光雷达镭神/` 中，实现了全套免 ROS 极简直驱与避障库：

### 3.1 免 ROS 纯 Python 直驱架构（`Lradar.py`）
* **通信标准**：通过 TTL 串口直连镭神 N10P 激光雷达，波特率固定为 **`460800` bps**；
* **二进制帧解析**：雷达输出包含固定帧头（`0xA5 0x5A`）、点数、起始角度、点云距离数组与校验码；单脚本在独立守护线程中实时将原始字节流解码为点云极坐标对 (θi, ρi)，全周解算延迟 < 15ms，极度节省 CPU。

### 3.2 细立柱检测与世界系时间滑窗拟合（`pole_tracker.py`）
* **点云聚类滤波**：利用欧几里得距离门限将稀疏点云分割为多个离散点簇；
* **几何拓扑判据**：当某个点簇的横向跨度满足 1cm ≤ W ≤ 4cm 且与背景墙体存在明显深度跃变时，判定为候选细立柱；
* **世界坐标系时间滑窗**：结合无人机自身实时位姿，将机体系下的立柱测量值转换至大地坐标系，在滑动时间窗口（如最近 10 帧）内做均值滤波与多项式拟合，彻底消除机身晃动造成的虚警。

### 3.3 16 项自动化单元测试（pytest）
该上游库自带了严密的单元测试套件：
```bash
cd drone-workspace/03_激光雷达SLAM避障
pytest 2d激光雷达镭神/
```
* **测试覆盖点**：
  1. 雷达数据校验和计算与坏包丢弃；
  2. 极坐标转直角坐标数学准确性；
  3. 细立柱判定边界容差（边界值、临界值）；
  4. 缺失点与盲区自动剔除。
* **工程纪律**：任何修改避障逻辑或适配新雷达的动作，必须在 PC 端跑通全部 16 项测试后方可推上板端。

## 4. 3D 激光雷达 SLAM（宇树 L1 + Point-LIO）

在工程 `03_激光雷达SLAM避障/3d激光雷达宇树/` 中，收纳了面向三维空间感知的高阶 SLAM 方案：
* **传感器**：宇树 Unitree L1 固态激光雷达（超大水平视场与垂直多线束）；
* **核心算法**：**Point-LIO**（Point-by-point LiDAR Inertial Odometry），直接在每个激光点到达时与内置 IMU 高频紧耦合更新流形状态，免去点云特征提取，在大动态无人机飞行中实现实时无漂移 3D 建图；
* **应用场景**：立体货架盘点（2024-D 题）多层三维障碍探测、复杂工业仓库自主导航。
