## 1. 动力系统匹配与推重比设计

在全国大学生电子设计竞赛（NUEDC）中，无人机赛题均有严格的物理尺寸和安全防护限制（例如 2024-D、2025-H 题硬性要求：**最大轴间距 ≤ 45cm、桨叶必须全防护**）。实战中推荐选用 210mm~250mm 轴距机架（5寸机），加装全包覆防护罩后外轮廓对角线严控在 42cm 以内，为狭窄空间穿障预留充足安全裕量。加装安全网后，旋翼面临额外的空气阻力与气流扰动，因此动力系统的推重比（Thrust-to-Weight Ratio）是整机设计的生命线。

### 1.1 推重比黄金法则
* **及格线**：T/W ≥ 2.0:1（整机全备重量 1000g 时，四轴最大总拉力需达到 2000g 以上）；
* **推荐区间**：2.2:1 ~ 2.5:1；
* **为什么不能低于 2.0**：当加装全包覆防护网后，旋翼下洗气流受阻，电机效率下降约 15%~20%；若推重比不足，无人机在执行急刹车、打偏航、或快速下降进入地面效应区时，将没有足够的动力裕量进行姿态自愈，导致不可逆的侧翻掉高。

### 1.2 经典电赛四轴动力推荐配置表
| 部件 | 推荐型号 / 参数 | 关键选型考量 |
| :--- | :--- | :--- |
| **无刷电机** | **2205 / 2306** (2300KV ~ 2450KV) | 定子直径 22~23mm，低速大扭矩，支持 4S 瞬态爆发响应 |
| **螺旋桨** | **5045 / 5146 三叶桨** | 5 寸高刚性桨叶，抗振动形变，兼顾升力与响应速度 |
| **动力电调** | **30A ~ 45A 四合一电调 (BLHeli_S / BLHeli_32)** | 支持 DShot300/DShot600 数字油门协议或 400Hz 传统 PWM |
| **动力电池** | **4S 1500mAh 100C 锂聚合物电池 (LiPo)** | 单片满电 4.2V（整组 16.8V），截止保护 3.6V，持续大电流放电 |
| **整机全备质量** | **900g ~ 1100g**（含防护网、机载电脑、T265、摄像头） | 严格控制机载配重，重心（CG）必须落在四轴对角线几何交点 |

## 2. 强电动力与弱电控制分级供电架构

电赛无人机系统集成了大电流无刷电机、高速单片机、图像处理器（树莓派/RDK X5）以及高灵敏度传感器（陀螺仪/磁力计），必须执行严格的三级供电隔离：

```text
       ┌────────────────────────┐
       │   4S 动力锂电池 (14.8V~16.8V) │
       └───────────┬────────────┘
                   │ 大电流动力母线 (XT60)
         ┌─────────┴─────────┐
         ▼                   ▼
┌──────────────────┐  ┌────────────────────────────────┐
│ 四合一动力电调 (ESC)│  │   DC-DC 开关降压电源模块 (BEC)  │
│ 直接驱动 4 个电机 │  │ 输出: 5V / 3A~5A 持续大电流    │
└──────────────────┘  └───────────────┬────────────────┘
                                      │ 纯净 5V 总线
                        ┌─────────────┴─────────────┐
                        ▼                           ▼
              ┌──────────────────┐        ┌──────────────────┐
              │  机载上位机计算机 │        │  飞控底板与微控制器│
              │ 树莓派 4 / RDK X5 │        │  STM32F405 / 407 │
              └──────────────────┘        └─────────┬────────┘
                                                    │
                                                    ▼ LDO 线性降压
                                          ┌──────────────────┐
                                          │ 3.3V 极其纯净微电总线│
                                          │ MPU6500 / 气压计 / │
                                          │ 磁力计 / 单片机内核│
                                          └──────────────────┘
```

### 2.1 供电抗干扰铁律
1. **地线（GND）单点汇流**：动力强电地线与微弱信号地线严禁形成闭合环路（Ground Loop），避免电机高速换向的高频杂波反串击穿单片机；
2. **电源退耦电容**：在主电源入口处必须并联一只 **35V 1000μF 高频低阻电解电容**，吸收电机急刹车时的反电动势浪涌电压；
3. **机载电脑独立供电**：严禁直接利用飞控板载的微型 5V 接口给树莓派或 RDK X5 供电（板载供电通常仅 500mA~1A，机载电脑满载拉满时会导致飞控失压瞬间掉电重启炸机）。

## 4. T265 硬件连接与冷启动避坑规范（现场实测实锤）

Intel RealSense T265 采用双目鱼眼相机与内置 Movidius Myriad 2 VPU 进行端侧自主 VIO 解算，在树莓派 4B / 机载 Linux 环境部署时，存在一个致命的底层时序陷阱：

### 4.1 硬件时序死锁机理剖析
* **现象**：将 T265 插在树莓派 4B 上，冷启动开机后，代码无法调用相机，`lsusb` 找不到设备或提示 `03e7:2150` 初始态无法加载固件，必须人手拔下 USB 线重新插一次才能正常工作；
* **根因**：树莓派 4B 的蓝色 USB 3.0 端口由独立的 **VIA VL805 PCIe 主控芯片**驱动。在开机上电瞬间，VL805 会对 USB 3.0 总线发起 5Gbps 的 SuperSpeed 链路时序协商；而 T265 内部的 Movidius 引导固件在上电瞬态极易发生超时，导致芯片的 USB PHY 硬件死锁挂起，内核疯狂报错：
  ```text
  [ 4397.068068] usb usb2-port1: Cannot enable. Maybe the USB cable is bad?
  [ 4397.068327] usb usb2-port1: unable to enumerate USB device
  ```
  此时芯片进入总线假死状态，无法响应任何固件刷写指令。

### 4.2 三大铁律解决方案
1. **物理接口铁律：必须插黑色 USB 2.0 口，严禁插蓝色 USB 3.0 口！**
   * 黑色 USB 2.0 走原生 High-Speed（480Mbps）协商，绝不触发 VL805 的 SuperSpeed 链路死锁；
   * T265 仅向外传输 6-DoF 位姿浮点数据，数据吞吐量不足 100KB/s，USB 2.0 带宽充裕 1000 倍以上，且实现**开机 100% 免拔插秒级自启激活**。
2. **udev 权限终结赋值（`:=`）**：
   * 在 `/etc/udev/rules.d/99-realsense-libusb.rules` 中，必须使用 **`:=`**（终结操作符），防止权限被系统其他规则篡改：
     ```udev
     SUBSYSTEMS=="usb", ATTRS{idVendor}=="03e7", ATTRS{idProduct}=="2150", MODE:="0666", GROUP:="plugdev"
     SUBSYSTEMS=="usb", ATTRS{idVendor}=="8087", ATTRS{idProduct}=="0b37", MODE:="0666", GROUP:="plugdev"
     ```
3. **免拔插软复位应急工具**：
   * 在 Linux 端安装 `sudo apt install usbutils`；若因异常断电卡在 `03e7:2150` 态，可通过后台执行：
     ```bash
     sudo usbreset 03e7:2150
     ```
     向端口发送 `USBDEVFS_RESET` 控制包，实现毫秒级软件“拔插”自愈。

## 5. 室内自主定位传感器横向实测对比

| 传感器类型 | 代表型号 | 工作原理 | 室内电赛环境优缺点 | 推荐应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **双目 VIO** | **Intel RealSense T265** | 双目鱼眼视觉 + 硬件 IMU 自主紧耦合 SLAM | **优点**：厘米级 3D 绝对坐标输出，无累积漂移，不占上位机 CPU。<br>**缺点**：对地面光照纹理有一定要求，怕强漫反射。 | **室内全局大范围航线循迹、穿框与网格自主巡查（首选）** |
| **激光 ToF 定高** | **TF-Luna / VL53L1X** | 940nm 飞行时间测距（单点激光） | **优点**：毫米级对地测距，不受门窗气流和气压突变影响。<br>**缺点**：遇吸光黑色地毯或镜面水面会偶尔丢锁。 | **室内定高闭环唯一推荐传感器（绝对替代传统气压计）** |
| **光流计 (Flow)** | **LC302 / PMW3901** | 微型底视图像帧间互相关测速 | **优点**：极轻（数克），不挑主控，直连飞控即可定点悬停。<br>**缺点**：只测速度不测绝对坐标，长距离巡航存在累积漂移。 | **低成本轻量机型微距稳定悬停辅助** |
| **气压计** | **MS5611 / SPL06** | 大气压差换算海拔高度 | **优点**：全天候室外宏观高度计。<br>**缺点**：**室内赛场严禁单用**（开门关风扇产生的大气压扰动会导致飞机瞬间掉地 30cm）。 | 仅作为室外宏观定高辅助，室内必须以激光 ToF 为准 |
