## 1. 30 秒认知：这是一套什么系统

2025 年电赛 H 题（野生动物巡查）的**完整参赛工程**——室内自主飞行四旋翼，四大模块：

```
┌─────────────────┐   UART 230400bps   ┌──────────────────┐   蓝牙   ┌─────────────────┐
│ STM32F405 飞控    │◄─────────────────►│ 机载上位机(树莓派4) │◄───────►│ 地面站            │
│ BirdFlight_V2.0  │   T265位姿/航点     │ • T265 定位       │          │ Nextion 串口触摸屏 │
│ • PID/ADRC/LQR   │                    │ • DFS/Dijkstra规划 │          │ • 动物识别语音播报  │
│ • uCOS-III       │                    │ • 视觉识别        │          └─────────────────┘
│ • 传感器驱动      │                    └──────┬───────────┘
└───────┬─────────┘                           │ USB
        │ PWM                                 ▼
     电机×4                        T265 双目 VIO + 下视摄像头
```

**与凌霄方案的三个根本区别**（详见第 7 节，防止两套方案互抄）：

| 事项 | 锡月（本方案） | 凌霄（`../02_凌霄飞控与空地协同/`） |
| --- | --- | --- |
| 飞控固件 | **BirdFlight_V2.0**（STM32F405 + uCOS-III） | ANO_LX（STM32F407 + 匿名 IMU 核） |
| **控制算法** | **就在仓库里**（`Control/` 目录） | **不在仓库里**（在匿名 IMU 核固件，不公开） |
| 串口波特率 | **230400** | **460800** |
| 地面站 | Nextion 串口屏 + 蓝牙（合规） | PyQt5 电脑上位机 |

## 2. 硬件清单（接手前先盘点）

| 类别 | 器件 | 用途 |
| --- | --- | --- |

## 4. 第一次上手：四步走

### 第 1 步 · 克隆仓库

```bash
git lfs install                                  # 先于 clone 执行，否则 LFS 大文件拉不下来
git clone https://github.com/LONEFORME/xiyue-drone.git 01_锡月无人机实战系统
```

### 第 2 步 · 桌面无硬件验证（不接任何设备，先跑通两件事）

**视觉识别**（核心模块单测式体验，无相机时用测试图）：

```bash
cd 01_锡月无人机实战系统/04_视觉识别
pip install opencv-python pyzbar numpy
python 集成视觉识别系统_示例.py
```

**路径规划**（纯算法，读 `02_树莓派机载主控/自启动/path_generator.py`，DFS 9×7 全覆盖 + Dijkstra 绕障，可配合 `02_树莓派机载主控/自启动/航点配置/航点配置_视觉版.txt` 的 8 个航点（z=1.5m）理解输入格式）。

> ✅ 通过标准：视觉示例能检出形状/颜色/同心圆/二维码；能口述"禁飞格号 → Dijkstra 重规划"的数据流。

### 第 3 步 · 机载上位机（树莓派）部署

```bash
# 板端安装依赖
pip install pyrealsense2 pyserial numpy opencv-python transformations

# 主入口启动（通过板载按键选择飞行模式，板端固定入口文件名）
python 02_树莓派机载主控/自启动/autoboot_main.py
```

关键文件都在 `02_树莓派机载主控/自启动/` 下：

| 文件 | 职责 |
| --- | --- |
| `autoboot_main.py` | 主入口，按键选择飞行模式（板端唯一固定入口名） |
| `A_fly_deal.py` | 飞行控制核心（FlyController 类：T265 + 串口 + 航点导航） |
| `path_generator.py` | 路径规划核心（DFS 网格覆盖 + Dijkstra 绕障重规划） |
| `A_DataDeal.py` | 四元数 → 航空坐标转换（T265 数据处理，板上原名） |
| `A_gpio_deal.py` | GPIO 外设驱动（按键 / LED / 蜂鸣器 / SSD1306 OLED） |

> 联调时先只接 T265 + 串口（不装桨），确认 230400 链路上有位姿/航点帧收发，再谈电机。

### 第 4 步 · 飞控固件编译烧录（Keil MDK）

1. 工程文件：`01_飞控固件/BirdFlight_V2.0/Project/BirdFlight_V2.0.uvprojx`；
2. Keil 打开 → 编译 → ST-Link/J-Link 烧录 STM32F405；
3. 控制算法全部在 `01_飞控固件/BirdFlight_V2.0/` 下（**这是本方案与凌霄最大的不同——控制律看得见、改得了**）：

| 目录 | 内容 |
| --- | --- |
| `Control/` | PID / ADRC / LQR / 神经元 PID |
| `Hardware/` | IMU / 气压计 / 激光 / 光流 / 超声波驱动 |
| `Mymath/` | Madgwick / Mahony / EKF 姿态解算 |
| `Parameter/` | T265 / 视觉 / 光流参数处理 |
| `uCOS-III/` | 实时操作系统 |

4. 首次上电先做**桌面绑桨测试**：不装桨上电，用上位机波形确认姿态解算收敛、无自激振荡（调参方法见学习路径指南 3.1 节）。

## 6. 关键参数与高频坑

1. **串口 230400，不是 460800**。凌霄/雷达那套 460800 配置照搬过来 = 链路静默无数据。接手后改任何串口初始化前，先确认当前是哪个项目的代码。
2. **两套飞控架构不能互抄**：BirdFlight_V2.0（uCOS-III + 自研控制律）≠ ANO_LX（匿名 IMU 核 + 0x41 帧）。从凌霄仓复制来的驱动/协议代码必须逐行核对帧格式。
3. **T265 在树莓派 4B 上请插黑色 USB 2.0 口（核心避坑）**：实测证实树莓派 4B 蓝色 USB 3.0 口的 VL805 主控在开机上电瞬间与 T265 存在 SuperSpeed 链路时序死锁，导致开机固件无法写入、总线掉线必须人工拔插；而插在黑色 USB 2.0 口带宽充裕且彻底避免开机死锁，上电开机代码秒级直接激活加载固件！另外 udev 规则必须用 `MODE:="0666"` 终结赋值防止被系统覆盖。
4. **地面站禁用普通电脑**：比赛规定地面端不能用通用计算机，所以是 Nextion 串口屏 + 蓝牙。调试期可以临时用 PC 串口助手替代屏幕，但正式形态必须回归串口屏。
5. **归档目录与测试快照**：`05_参赛代码归档/` 中的 7z 包为历史整包封存；`用户测试代码/` 整理了备赛期间 15 个功能快照（含视觉伺服 A_visual_deal.py 原型），实机现役运行一律使用 `02_树莓派机载主控/自启动/`。
6. **航点文件是真源**：修改定点巡航航线一律改 `02_树莓派机载主控/自启动/航点配置/航点配置_*.txt`，部署时拷为板端 `router.txt`，不要在代码里硬编码航点。
