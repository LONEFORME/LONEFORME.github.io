## 1. 30 秒认知：这是一套什么系统

匿名凌霄（ANO_LX）飞控全栈库 = **官方资料 + 自研空地协同系统 + 历年电赛参考**。自研系统已实飞验证（演示视频在 `自研系统/演示视频/`：二维码识别降落 / 火源定位 / 自主绕杆 / 移动平台动态降落）：

```
┌──────────────┐ 0x41实时控制帧 460800 ┌──────────────┐
│ STM32F407     │─────────────────────►│ 匿名 IMU 核    │   ← 真正的 PID 姿态/位置闭环在这里
│ FcSrc 主程序   │◄─────────────────────│ （固件不公开）  │
└──────┬───────┘   PWM 回传            └──────────────┘
       │ /dev/ttyS1                        ▲
       │                                   │ UDP/USB
┌──────┴───────────────────────────────────┴──────┐
│ RDK X5 / 树莓派 机载状态机（机载上位机）    │◄──► K230 边缘视觉 (/dev/ttyS7)
│  • 任务一：伴飞与抛投   • 任务二：移动平台动态降落    │◄──► T265 双目 VIO
└──────┬──────────────────────────────────────────┘
       │ 蓝牙透传 /dev/bt_serial（DCP v1 协议）
```

## 2. 第一课：控制律不在这个仓库里——别找了

这是本仓最重要的一条认知，先建立再动手：

1. **`FcSrc` 是"输入、输出主程序"**，只做三件事：①采遥控 + 传感器；②把速度目标打成 **`0x41` 实时控制帧**发给匿名 IMU 核；③收 `pwm_to_esc` 回传的 PWM。
2. **真正的 PID 姿态/位置闭环在匿名 IMU 核固件里，官方不公开**。官方基线 `ANO_LX.c:147` 自带注释："实时控制帧，自主开发闭环控制，在这里赋值即可"——官方基线本身就是**程控模板**。
3. **版本协同铁律**：IMU 固件 **119 版本以上使用新版控制帧**，上位机与飞控固件版本必须配套。最新固件见原厂包 `../05_凌霄官方原厂资料包/7.凌霄IMU固件/ANO_LX-hw130-sw136.ano`（已同步至 `官方资料/文档/04-IMU固件/`）。
4. **程控可用接口**：`rt_tar.st_data.vel_x / vel_y / vel_z`（cm/s，机头坐标系）+ `yaw_dps`（°/s），走 0x41 帧；**只在"定点模式 + 摇杆中位"时有效**，程控模式下摇杆注入全无效。
5. **不要重做代码溯源**——八轮追问的源码级比对结论已存于 `.workbuddy/memory/lingxiao-lineage.md`，需要时直接读。

## 4. 第一次上手：三条路径按需选

### 路径 A · 新手打底层（先跑官方基线）

1. **装环境**：按 `官方资料/工具环境/开发环境配置说明.md` 装 Keil MDK + J-Link 驱动 + 匿名上位机；Keil 芯片支持包（STM32F4/TM4C/MSP432 DFP）在原厂包 `../05_凌霄官方原厂资料包/3.开发环境安装/`（DFP 体积大不入仓，从原厂包取）。
2. **编译官方纯净基线**：Keil 打开
   `官方资料/固件基线/ANO_LX_FC/ProjectSTM32F407/ANO_LX_STM32F407.uvprojx`
   （另有 MSP432 / TM4C 工程同目录），编译烧录。
3. **跑官方例程**：`官方资料/例程/` 下
   `例程1.一键起飞_降落/`、`例程2.一键任务_起飞+悬停+前进+右移+降落/`——体验程控模板的正确打开方式。
4. **读协议**：`官方资料/文档/01-用户手册与通信协议/匿名通信协议V7.pdf`（权威版）。

### 路径 B · 部署自研系统（自研系统，接手主力路径）

机载端（RDK X5 / 树莓派 4B，Python 3.10+）：

```bash
# 1) 依赖与单测（200+ 项测试套件，先在 PC 上全绿）
pip install pytest pyserial simple-pid numpy psutil opencv-python
cd 自研系统/机载上位机
pytest shared/                    # DCP v1 协议库自测
pytest competition_2026_d/        # 主任务状态机单测

# 2) 板端部署：udev 固定串口别名（蓝牙→/dev/bt_serial，雷达→/dev/radar）
sudo cp 部署/udev/99-drone-serial.rules /etc/udev/rules.d/
sudo cp 部署/udev/99-realsense-libusb.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger

# 3) 开机自启动服务（可选，调试期可先手动跑）
sudo cp 部署/systemd/competition-2026-d-autostart.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now competition-2026-d-autostart.service
```

> ⚠️ 自启动服务会**独占串口并做预检**后等按键起飞——手动调试串口前先 `systemctl stop competition-2026-d-autostart`，否则"接上了但打不开串口"。

任务入口：`competition_2026_d/auto_start.py`（安全门禁 → 任务分发 → 心跳守护）；标定参数真源是 `competition_2026_d/config.json`。配套地面站与外围：

- **地面站**：`自研系统/地面站/`（PyQt5 只读遥测，400×500cm 实时地图 + 中文语音播报）；
- **边缘视觉**：`自研系统/边缘视觉/`（K230 CyberCAM）；
- **地面小车**：`自研系统/地面小车/`；
- **协同协议**：`自研系统/规范/communication_protocol.md`（DCP v1，改空地通信前必读）。

### 路径 C · 借鉴历年方案（只作参考）

`参考工程/` 下三套：`2024-NUEDC-D/`（2024-D 三维巡航）、`2022-HUST/`（飞控 + Python SDK + 雷达避障）、`UAV-2023/`（含 SolidWorks 机械与 3D 打印 STL，`MichanicalSolution/`）。**这些是往届参考工程，不是自研成果**——写报告、答辩时与 `自研系统/文档/EDC-2026-D-Report.md`（自研 2026 省赛 D 题报告）严格区分。

## 6. 关键参数与高频坑

1. **串口 460800**（飞控/雷达），漏配波特率 = "接上了但没数据"。
2. **0x41 帧的生效条件**：定点模式 + 摇杆中位。程控"发指令没反应"先查模式与摇杆状态，再查波特率与版本配套。
3. **IMU 固件版本必须 ≥119 并与上位机协同**（新版控制帧）；升级方法见原厂包内《匿名-V7版本上位机固件升级使用方法.pdf》。
4. **官方帧无校验**；自研链路（DCP v1）补了 CRC16 校验与帧类型——两套协议不要混接。
5. **编译产物已入 `.gitignore`**（`.o/.axf/.d/__pycache__`），提交前确认没有夹带；Keil DFP 大文件不入仓，从原厂包获取。
6. **改 T265 相关逻辑**：`自研系统/部署/watchdog/t265_monitor.py` 看门狗会做硬件级复位自愈（自 rdk-x5-flight-system 并入），联调时不要随手停掉它。
7. **雷达算法上游**：立柱追踪/避障算法改自 `../03_激光雷达SLAM避障/2d激光雷达镭神/无人机避障应用/`（改后必须 16 项 pytest 全绿，见其 AGENTS.md）。
