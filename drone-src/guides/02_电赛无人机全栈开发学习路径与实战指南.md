## 1. 系统信号流与全栈开发逻辑

无人机自主作业系统涉及硬件动力、飞控算法、机载感知、图论规划与空地通信等多个子系统的深度耦合。系统开发需遵循传感器数据到执行机构的确定性物理信号流：

```
[底层硬件动力] ──► [姿态与高度闭环] ──► [室内无GPS定位] ──► [视觉特征对准] ──► [网格规划避障] ──► [合规地面交互]
 (推重比/减震)     (串级PID/ToF定高)   (T265/光流VIO)    (像素反投影/IBVS)  (DFS遍历/Dijkstra)  (Nextion屏/语音)
```

### 核心软件架构：事件驱动与有限状态机（FSM）
在工程实现中（如凌霄 AUV、锡月），机载主控严禁采用单线程阻塞式 `time.sleep()` 轮询，统一采用**线程安全有界队列的事件总线（Event Bus）**与**七阶有限状态机（FSM）**：
```
[IDLE 待机自检] ──► [TAKEOFF 垂直起飞] ──► [NAVIGATE 航线巡视与避障]
                                                     │
[END 停机归档] ◄── [LAND 触地断电] ◄── [HOVER_WAIT 低空悬停稳态] ◄── [DESCEND 一阶降高]
```
- **DRY_RUN 桌面零硬件仿真**：在真机实飞前，必须通过 `DRY_RUN` 软件环境 Mock 传感器输入，在 PC 端跑通全部状态流转与单测，确认无死锁后再行下地通电。

## 3. 四大技术模块核心原理与实现

### 3.1 飞控底层动力学与控制算法

#### 1. 动力匹配与推重比计算
加装全包覆安全防护网后，气动阻风面导致有效升力衰减 **15% ~ 20%**。动力系统需在完全装配防护网状态下校准：
$$\text{推重比} = \frac{\sum_{i=1}^{4} T_{\text{max}, i}}{m_{\text{total}} \cdot g}$$
- **合理取值区间**：**2.0 ~ 2.5 : 1**；
- **参数示例**：整机全备质量（含机载上位机（树莓派 4）、T265、电池及防护网）控制在 **900g ~ 1100g**，四轴总推力需达到 **2000g ~ 2600g**（典型硬件组合：2205/2306 无刷电机 + 5 寸大螺距桨 + 4S 1500mAh 100C 动力锂电池）。

#### 2. 串级 PID 控制架构
参考 `01_锡月无人机实战系统/01_飞控固件/BirdFlight_V2.0/Control/`，姿态稳定采用串级闭环控制：
```
[期望角度 Roll/Pitch] ──(外环P)──► [期望角速度] ──(内环PID)──► [PWM混控输出] ──► 电机驱动
         ▲                                ▲
     IMU 姿态解算                      陀螺仪角速度
```
- **内环（角速度环，500Hz 执行周期）**：抑制机械震颤与风扰，整定方法为先提升比例项 $P$ 直至机体出现微小高频振荡，微调回退后引入微分项 $D$ 抑制超调；
- **外环（角度环，100Hz 执行周期）**：负责跟踪目标姿态倾角，通常采用纯比例项 $P$ 控制。

#### 3. 自抗扰控制（ADRC）扰动补偿机制
在室内近地面飞行中，地面效应与空调紊流会形成非线性扰动。锡月固件引入了自抗扰控制（ADRC）：
- 构造**扩张状态观测器（ESO）**，将系统未建模动态及外部气流扰动统一作为总扰动进行实时状态观测；
- 在控制律输出端对估计出的扰动量进行实时前馈消除，增强悬停抗扰能力。

### 3.2 室内无 GPS 厘米级自主定位

#### 1. 传感器配置方案
- **高度测量**：采用 **ToF 激光测距传感器（如 TF-Luna、VL53L1X）**。由于气压计在室内受门窗通风和地面气压波动影响严重（存在 10~30cm 的动态误差），超声波容易受地毯吸波衰减，ToF 传感器能够提供不受气流干扰的毫米级垂直距离反馈。
- **平面定位**：采用 **Intel RealSense T265 视觉惯性里程计（VIO）**。其内置专用视觉处理单元（VPU），能够以 200Hz 频率独立解算 6 自由度空间位姿，不占用机载主控 CPU 计算资源。

#### 2. 空间坐标系变换模型
T265 的输出坐标系与飞行控制坐标系存在几何映射关系。  
参考 `01_锡月无人机实战系统/02_树莓派机载主控/自启动/A_DataDeal.py`：
设 T265 输出的四元数为 $q = (w, x, y, z)$，转换为欧拉角：
$$\text{Roll} = \arctan2\left(2(wy + xz), 1 - 2(x^2 + y^2)\right)$$
$$\text{Pitch} = \arcsin\left(2(wx - yz)\right)$$
$$\text{Yaw} = \arctan2\left(2(wz + xy), 1 - 2(x^2 + z^2)\right)$$
结合机体安装偏角，将传感器坐标系下的位置向量 $(X_{\text{t265}}, Y_{\text{t265}}, Z_{\text{t265}})$ 正投影至大地坐标系 $(X_{\text{world}}, Y_{\text{world}}, Z_{\text{world}})$，供位置环与航点跟踪调用。

#### 3. T265 硬件连接与冷启动避坑规范（实测实锤）
在工程落地中，T265 的电气与驱动配置极易出现“开机无法激活固件、必须人工拔插”的顽疾，必须遵守以下三项铁律：
1. **接口必须插黑色 USB 2.0，严禁插蓝色 USB 3.0**：
   * 树莓派 4B 蓝色 USB 3.0 主控（VIA VL805）在系统开机上电瞬间对 T265 发起 SuperSpeed 握手极易产生时序协商超时，导致 T265 内核芯片（Movidius Myriad 2）陷入硬件 PHY 死锁，表现为内核报错 `Cannot enable. Maybe the USB cable is bad?` 且总线彻底掉线，必须物理断电拔插；
   * 插在黑色 USB 2.0 口时，完全规避该死锁缺陷，480Mbps 带宽传输 6-DoF 位姿数据绰绰有余，开机脚本直接秒级自启加载固件！
2. **udev 规则使用 `:=` 终结赋值**：
   * 在 `/etc/udev/rules.d/99-realsense-libusb.rules` 中必须使用 `MODE:="0666"` 终结赋值，防止被系统其他规则篡改为 root 专属：
     ```udev
     SUBSYSTEMS=="usb", ATTRS{idVendor}=="03e7", ATTRS{idProduct}=="2150", MODE:="0666", GROUP:="plugdev"
     SUBSYSTEMS=="usb", ATTRS{idVendor}=="8087", ATTRS{idProduct}=="0b37", MODE:="0666", GROUP:="plugdev"
     ```
3. **免拔插软复位工具**：安装 `usbutils`，若极端情况下卡在 `03e7:2150` 引导态，可通过执行 `sudo usbreset 03e7:2150` 实现免拔插软复位。

### 3.3 机载视觉检测与物理坐标反投影

#### 1. 赛场光照抑制与阈值处理
参考 `01_锡月无人机实战系统/04_视觉识别/集成视觉识别系统.py`：
1. **底层曝光锁定**：在相机采集驱动中显式禁用自动曝光（AE），固定曝光时间与传感器增益，消除 50Hz 工频室内光源频闪；
2. **HSV 色彩空间阈值分割**：采用 HSV 空间降低环境光强度的干扰，针对目标颜色设置双区间门限，确保边界完整性。

#### 2. 同心圆起降靶标判定算法
通过几何拓扑特征区分实心圆与同心起降靶标：
- **圆度判据**：计算轮廓面积 $A$ 与周长 $P$ 的几何关系 $C = \frac{4\pi A}{P^2}$，当 $C > 0.82$ 时判定为圆形候选区；
- **层级拓扑分析**：通过轮廓层级树（`cv2.RETR_TREE`）检验是否存在内外两层包含轮廓，且内外轮廓的几何中心偏移小于设定阈值（$< 5\text{ 像素}$），内外轮廓面积比满足标定参数。

#### 3. 单目针孔模型物理反投影
在获取图像中心偏差后，需将像素坐标系偏移量转换为机体物理位移量。  
设图像中心坐标为 $(c_x, c_y)$，目标中心像素为 $(u, v)$，当前激光定高测量值为 $Z$，相机标定焦距为 $f_x, f_y$：
$$\Delta X_{\text{body}} = \frac{Z \cdot (u - c_x)}{f_x}, \quad \Delta Y_{\text{body}} = \frac{Z \cdot (v - c_y)}{f_y}$$
将物理偏差 $(\Delta X_{\text{body}}, \Delta Y_{\text{body}})$ 传入速度控制器计算输出速度期望：
$$V_x = K_p \cdot \Delta X_{\text{body}}, \quad V_y = K_p \cdot \Delta Y_{\text{body}}$$
引导无人机平稳向靶标正上方收敛，消除下视对准误差。

#### 4. 机载局域网视频推流与自动广播发现
参考 `01_锡月无人机实战系统/04_视觉识别/OpenVision.py`：
- **UDP 图像与直方图流传输**：采用轻量 UDP 数据报将机载相机实时图像与直方图数据压缩发送给地面端，保障高实时性与低延迟；
- **局域网自动广播握手（Zero-Config）**：机载端通过向广播地址发送握手请求包，自动监听地面站的回复并提取其动态 IP 地址，彻底避免每次切换网络手动修改代码中 IP 的痛点。

### 3.4 离散图论规划与嵌入式交互终端

#### 1. 离散网格拓扑建模与路径求解
以 2025-H 题 450cm × 350cm 场地为例，将其抽象为包含 63 个节点的拓扑图 $G(V, E)$。  
参考 `01_锡月无人机实战系统/02_树莓派机载主控/自启动/path_generator.py`：
- **全覆盖扫描算法**：利用深度优先搜索（DFS）或往复式蛇形遍历算法，计算遍历所有无障碍节点的全局航线；
- **动态避障重规划**：当输入禁飞网格编号时，将拓扑图中连接禁飞节点的对应边置为不可通行状态，调用 **Dijkstra** 最短路径算法计算绕行拓扑路径，更新航点序列并注入飞控。

#### 2. 自制嵌入式地面终端系统
根据禁止使用通用计算机的要求，地面站由微控制器与专用交互屏构成：
```
[Nextion 串口触摸屏] ◄──(USART 串口)──► [STM32/ESP32 地面主控] ◄──(无线数据链路)──► [机载树莓派]
                                               │
                                               ▼
                                      [SYN6288 语音合成芯片] ──► 现场音频播报
```
- **触摸屏交互**：屏幕显示网格分布，通过触摸按键配置禁飞区与作业模式；
- **语音状态报靶**：地面微控制器接收机载回传的目标信息，构建 GB2312 协议数据帧发送至语音芯片完成语音报靶。

#### 3. 激光雷达点云避障与立柱追踪（免 ROS 纯 Python 直驱）
参考 `03_激光雷达SLAM避障/2d激光雷达镭神/免ROS直驱/Lradar.py` 与 `pole_tracker.py`：
- **免 ROS 纯 Python 直驱**：脱离重量级 ROS 框架，单脚本直接解析镭神 N10P 串口二进制极坐标数据帧，提取 $360^\circ$ 距离点云；
- **细立柱检测与世界系滑窗跟踪**：针对电赛 2020-D、2026-D 等细立柱（$\Phi \le 2\text{cm}$）场景，采用点云聚类滤波与世界坐标系下的时间滑窗拟合，稳定滤除噪点并锁定立柱坐标；
- **单元测试质量保障**：该算法自带 **16 项 pytest 自动化单元测试**，在新队员修改避障阈值或适配新雷达后，可直接在 PC 端脱机运行测试套件，确保避障逻辑零 Regression。

### 阶段一：动力系统匹配与稳定悬停

```
[阶段验收指标]
1. 动力系统在装配全套防护网状态下，起飞推重比实测 ≥ 2.0:1；
2. 飞行器一键自主起飞至 1.2m 高度并进入悬停状态；
3. 在侧向气流干扰下持续悬停 60 秒，水平漂移半径 ≤ 15cm，垂直高度波动 ≤ 5cm；
4. 遥控器急停开关动作后，电机在 0.2 秒内完全切断动力输出。
```

## 6. 常见系统故障诊断与解决措施

| 故障现象 | 潜在根本原因 | 工程解决方案 |
| :--- | :--- | :--- |
| **电机大推力起飞瞬间，机载主控板异常复位** | 动力锂电池瞬态放电压降造成输入电压低于机载板最小工作阈值 | 飞控与机载板必须分别配置独立的高压工业级 DC-DC 降压模块，机载电源入口并联低 ESR 滤波电容。 |
| **测试现场数传丢包严重，指令延迟增大** | 现场 2.4GHz 频段信道拥塞，无线信号发生同频碰撞干扰 | 通信协议设计帧序号与 ACK 重传机制；数传硬件优先切换至 433MHz / 915MHz 频段。 |
| **悬停时机体出现高频颤抖，随后姿态逐渐发散** | 螺旋桨或电机动平衡不良引发高频机械振动，导致陀螺仪积分漂移 | 使用动平衡仪对每片螺旋桨进行配重调整；飞控安装板加装硅胶阻尼减震垫。 |
| **下视相机在顶灯环境下画面频繁闪烁并造成误检** | 室内照明工频频闪导致相机默认的自动曝光算法持续剧烈调整 | 在摄像头驱动初始化代码中强制关闭自动曝光功能，根据现场环境照度手动配置曝光时间与增益。 |
| **加装安全防护网后飞行器垂直升力不足** | 防护网网格阻风面过大或产生反向紊流，造成升力效率衰减 | 改用高强度细尼龙线编制防护网，更换大螺距高升力桨叶，确保整体动力推重比在 2.2:1 以上。 |
| **整机尺寸超出试题限定包络要求** | 设计仅考虑轴距，忽略了外凸弧形防撞框或倾斜天线的最大外缘尺寸 | 机架结构设计时将外轮廓对角线尺寸控制在 42cm 以内，为外部线缆与外设留出充足尺寸冗余。 |
