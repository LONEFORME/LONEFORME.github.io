## 1. 电赛机载视觉的三大恶劣挑战与抑制对策

无人机机载相机在室内赛场运行时，与工业固定相机面临截然不同的恶劣光学环境：

| 挑战现象 | 物理根因 | 工程及格对策（必须固化在驱动层） |
| :--- | :--- | :--- |
| **画面明暗横条纹滚屏（频闪）** | 室内赛场多采用 50Hz 工频荧光灯或 LED 灯，相机自动曝光时间与灯光交流波峰不匹配 | **强制锁定曝光（禁用 AE）**：在相机初始化代码中关闭自动曝光，将曝光时间强制定为 $1/100\text{s}$（10ms）或其整数倍，彻底消除频闪滚屏。 |
| **高速飞行边缘拖影（运动模糊）** | 曝光时间过长叠加无人机快速机动 | **提升增益（Gain）并压低曝光**：以适度牺牲画质噪点为代价，将单帧曝光压缩至 $2\text{ms} \sim 5\text{ms}$ 以内，确保边缘锐利。 |
| **地毯与环境漫反射色差** | 场地不同位置的光照不均匀，阴影区与高光区 HSV 严重偏移 | **双色彩空间联合判定**：结合 HSV 空间的色调（H）与 BGR 空间的色彩通道比例差，动态放宽光照分量（V）的门限。 |

## 2. OpenCV 经典几何与色彩特征工程

参考源码：`04_OpenCV视觉检测系统/src/综合视觉识别系统.py` 与 `01_锡月/04_视觉识别/集成视觉识别系统.py`

### 2.1 11 色 HSV/BGR 双空间自适应阈值分割
为消除单通道阈值对光照波动的敏感性，系统构建了覆盖常见赛题的 11 色标定字典（红/橙/黄/绿/青/蓝/紫/粉/白/灰/黑）：
```python
# 示例：针对红色在 HSV 空间跨越 0°/180° 边界的双区间融合
lower_red1 = np.array([0, 100, 100])
upper_red1 = np.array([10, 255, 255])
lower_red2 = np.array([160, 100, 100])
upper_red2 = np.array([180, 255, 255])
mask_red = cv2.bitwise_or(cv2.inRange(hsv, lower_red1, upper_red1),
                          cv2.inRange(hsv, lower_red2, upper_red2))
```

### 2.2 几何轮廓多边形逼近（`cv2.approxPolyDP`）
利用道格拉斯-普克（Douglas-Peucker）算法对二值化轮廓曲线进行多边形拟合：
* **逼近精度**：$\epsilon = 0.02 \times \text{Perimeter}$（周长）；
* **顶点数分类**：
  * $N = 3$：严格判定为**三角形**；
  * $N = 4$：计算宽高比 $\text{Aspect Ratio} = W / H$，接近 1.0 为**正方形**，偏离 1.0 为**长方形**；
  * $N = 5$：判定为**五边形**；
  * $N > 6$：进入圆形度判定逻辑。

### 2.3 起降同心圆（靶标）严格判据
电赛起降靶心通常为“黑白相间”或“红白相间”的同心圆环，判定必须满足两大数学约束：
1. **圆形度判据（Circularity）**：
   $$C = \frac{4\pi A}{P^2} \ge 0.80 \sim 0.85$$
   （理论上纯圆为 1.0，方块等几何体通常 $< 0.78$）；
2. **内外轮廓拓扑层级（Hierarchy）**：
   通过 `cv2.findContours(..., cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)` 构建拓扑层级树，检验外层圆轮廓是否包含恰好一个内层子轮廓，且两个轮廓的外接圆心欧氏距离 $< 5\text{ 像素}$，内外圆半径比例符合预设模具尺寸。

## 3. 单目针孔模型物理反投影与降落对准闭环

参考源码：`01_锡月/04_视觉识别/02_飞行控制与视觉集成/qifei必飞完.py`

获取图像中靶心的像素中心 $(u, v)$ 后，必须将其映射为大地世界坐标系下的物理偏差米数 $(\Delta X, \Delta Y)$，方可驱动飞控闭环收敛：

```text
[图像像素偏差 (u - cx, v - cy)]
             │
             ├── 激光 ToF 实测高度 Z
             ├── 相机标定内参焦距 (fx, fy)
             ▼
[机体系物理水平位移偏差 (ΔX_body, ΔY_body)]
             │
             ├── 机体实时偏航角 Yaw
             ▼
[大地系物理水平位移偏差 (ΔX_world, ΔY_world)] ──► P 控制器输出速度期望 ──► 飞控收敛对准
```

### 3.1 物理反投影数学推导
设相机主点为 $(c_x, c_y)$，标定焦距为 $f_x, f_y$，机载 ToF 测得的当前离地净高为 $Z$：
$$\Delta X_{\text{body}} = \frac{Z \cdot (u - c_x)}{f_x}, \quad \Delta Y_{\text{body}} = \frac{Z \cdot (v - c_y)}{f_y}$$

### 3.2 速度前馈比例收敛控制
为避免到达目标上方时姿态剧烈超调造成震荡，采用比例速度控制引导对准：
$$V_x = \text{clamp}(K_p \cdot \Delta X_{\text{body}}, -V_{\max}, V_{\max})$$
$$V_y = \text{clamp}(K_p \cdot \Delta Y_{\text{body}}, -V_{\max}, V_{\max})$$
* **降落切换阈值**：当水平综合误差 $\sqrt{\Delta X^2 + \Delta Y^2} < 3\text{cm}$ 且持续保持 0.5 秒以上，状态机自动切入 `DESCEND` 降落停机阶段。

## 4. 官方底层视频流与广播握手真源（`OpenVision.py`）

参考源码：`01_锡月无人机实战系统/04_视觉识别/OpenVision.py`

在机载上位机向地面端传输画面时，传统的 TCP 连接在飞行抖动丢包时会产生灾难性的“帧堆积与秒级延迟”。本工作区找回的失传真源 `OpenVision.py` 采用了专为无人机优化的通信机制：

1. **UDP 无阻塞流式传输**：
   * 采用无连接的 UDP 套接字，单帧图像经 JPEG 压缩后分片直发；即使偶遇无线丢包，下一帧到达瞬间立刻覆盖显示，端到端延迟控制在 $30\text{ms}$ 以内；
2. **局域网自动广播发现（Zero-Config）**：
   * 编写了 `find_ground_station_ip()` 函数，机载端通过向 `255.255.255.255:6055` 发送 `DRONE_DISCOVERY_REQUEST` 广播包；
   * 地面站监听到后自动回传 IP 地址，机载端瞬间锁定目标，**彻底告别比赛现场切换路由器后手动登机改 IP 的麻烦**。
