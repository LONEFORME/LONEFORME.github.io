## 1. 电赛地面站合规强制红线

全国大学生电子设计竞赛（NUEDC）对地面操作终端有着极其严厉的一票否决级要求：
* **红线条款**：**严禁使用通用计算机（PC 笔记本电脑、便携工控机、平板电脑及标准全尺寸键盘）** 作为地面站直接参与测试；
* **合规解法**：必须自制由**微控制器（单片机）驱动的便携式嵌入式手持终端**，通过专用串口触摸屏（如 Nextion / 陶晶驰）、物理按键、无线透传模块（数传/蓝牙）以及语音合成芯片完成人机交互。

## 2. Nextion / 陶晶驰串口触摸屏交互设计与通信协议

参考源码：`01_锡月无人机实战系统/03_地面站/地面站主控程序.py` 与 `03_地面站/README.md`

Nextion 智能串口屏内置图形渲染引擎，主控仅需通过 TTL 串口（波特率通常为 9600 或 115200）向屏幕发送标准 ASCII 文本控制指令。

```text
[机载上位机 (树莓派)]
        │ 蓝牙无线透传 (9600bps)
        ▼
[地面主控处理端] ──► 多进程并行处理 ──┬──► (TTL 串口 0xFF 0xFF 0xFF) ──► [Nextion 串口触摸屏]
                                    │
                                    └──► (GB2312 协议编码) ──────► [SYN6288 语音合成芯片]
```

### 2.1 结束帧协议铁律（`0xFF 0xFF 0xFF`）
Nextion 屏幕的解析器以连续三个 `0xFF` 字节作为单条指令的结束判定，缺少该结束符将导致指令永远悬挂在屏幕接收缓冲区：
```python
def send_nextion_cmd(ser, cmd_str):
    """向串口触摸屏发送指令的标准封包函数"""
    ser.write(cmd_str.encode('gbk'))
    ser.write(bytearray([0xff, 0xff, 0xff]))
```

### 2.2 常见控件指令集
* **更新文本显示**：`t0.txt="动物: 老虎"`
* **计数器自增**：`n0.val++`（统计检出的目标数量）
* **切换页面**：`page page1`
* **进度条与图形刷新**：`j0.val=85`

### 2.3 多进程并发通信与 SYN6288 语音报靶
在 2025-H 题（野生动物巡查）中，检出动物后要求地面站即时发出语音播报。为防止串口读写阻塞导致屏幕卡死，系统采用 `multiprocessing` 架构：
1. **进程 A（蓝牙接收进程）**：全速监听机载树莓派通过蓝牙上传的目标分类与网格坐标，解析后放入线程安全队列 `Queue`；
2. **进程 B（交互与屏幕刷新进程）**：消费队列数据，驱动 Nextion 屏幕刷新航迹与计数器；
3. **语音合成驱动**：将文字按 GB2312 编码打包成帧头为 `0xFD` 的语音帧，发送给 SYN6288 芯片完成现场高保真语音播报。

### 3.2 拓竹 3D 打印切片参数黄金建议
1. **耗材材质选型**：
   * 结构件（机架、保护罩、底板）：首选 **PETG** 或 **PLA-CF（碳纤维增强 PLA）**，绝不能使用纯脆性 PLA（脆性高，轻微碰壁即崩裂）；
   * 减震缓冲件（相机座、云台垫片）：使用 **TPU 95A 柔性耗材**，利用橡胶弹性吸收高频高振。
2. **切片关键参数（Bambu Studio）**：
   * **壁厚圈数（Wall Loops）**：设置为 **4 ~ 5 层**（电赛零件强度主要由外壁提供，而不是填充率）；
   * **填充率与图案**：设置 **25% ~ 35% 陀螺线（Gyroid）** 填充，各向同性受力，兼顾极轻重量与超高抗扭强度；
   * **支撑类型**：复杂悬臂使用 **树状支撑（Tree Support）**，接触面平整且极易徒手剥离。
