🛡️ 项目介绍 · PROJECT INTRODUCTION

基于激光雷达的
远程安防监控系统

边缘智能 · 多模态融合 · 已落地运行 —— 以激光雷达为空间感知核心，融合视觉、指纹、声学与温度感知的多模态智能安防中枢

主控平台：地瓜派 RDK X5（10 TOPS BPU）
感知核心：镭神 N10P 激光雷达 · 360° / 12Hz
监控形态：Web 远程监控台（6 Tab）

项目概览

Project Overview
⚠️ 传统可见光监控的三个短板
  • 夜间低照度失效：纯可见光相机在暗光下基本失明；
  • 缺少空间深度：画面无法量化距离，误报难抑制；
  • 无物理反制手段：只能记录，不能拦截与告警驱离。
🎯 本方案的应对
  • 激光雷达空间感知：360° 点云测距，不依赖光照条件；
  • 量化判定三级状态机：距离 / 点数 / 持续时间三重防抖；
  • 门禁与声光现场反制：舵机门禁 + 蜂鸣器 + 抓拍存证。
✓ 10 TOPS BPU 边缘算力
✓ 360° / 12Hz 雷达扫描
✓ 双摄 1080P + 720P
✓ 6 类感知子系统

雷达感知与防区算法

Radar Sensing Pipeline
🔄 感知算法流水线
  • ① 电子围栏扇区过滤：只关注布防扇区内的点云；
  • ② 静态背景自学习滤除：开机 3 秒标定环境，消除固定物干扰；
  • ③ 欧氏邻域聚类：0.18m 半径成簇，最少 5 点抑制噪声；
  • ④ 三级状态机判定：空间 / 数量 / 时间三重防抖。
🛠️ 雷达驱动自愈
  • 空点圈检测：连续 15 秒只有无效距离点，判定上电初期异常；
  • 自动重启驱动：两次尝试间隔 ≥60 秒防抖；
  • 秒级恢复：实测重启后恢复约 12Hz、300+ 有效点。
✓ 扇形防区 315°~45°（跨 0°）
✓ 检测距离 0.1~8.0m · 报警阈值 0.5m
✓ 连续计数阈值 10 · 保持 0.2s

三级报警与告警存证

Alarm & Evidence
🟢 正常 STANDBY
  • 防区内无目标或点数少；
  • 绿灯常亮，系统待机。
🟡 警告 WARNING
  • 点数少或持续短；
  • 黄灯常亮，提示关注。
🔴 报警 ALARM
  • 点数 ≥ 阈值且持续满足；
  • 红灯常亮 + 蜂鸣器。
📸 告警存证链
  • 报警确认 → 自动抓拍（Quality 95）→ FIFO 相册 50 张循环淘汰 → 事件审计可导出；
  • 抓拍冷却 3 秒防重复刷屏；入侵 / 陌生面孔 / 非法指纹 / 手动操作均可触发存证。

智能门禁系统

Smart Access Control
1️⃣ 人脸识别引擎
  • InsightFace：SCRFD 检测 + ArcFace 512 维特征；
  • 双眼连线 Roll 校正 + 鼻尖水平偏离估算；
  • ≤35° 侧脸拦截，正脸才进入比对；
  • 置信度达标自动开门（阈值 0.35 可调）。
2️⃣ 指纹识别门禁
  • ML-FPM007 面阵半导体模组（UART 直连）；
  • 1~100 编号录入 · 同一手指三次采集确认；
  • 按编号删除 · Touch 触摸唤醒省电；
  • 非法试探联动声光报警。
3️⃣ 舵机齿条门禁
  • 360° 连续旋转舵机 + 齿条传动机构；
  • 毫秒级时间微积分构建虚拟编码器；
  • 开度 0~100% 实时落盘 · 断电不丢步；
  • 行程 5.3s · 一键开关 / 急停 / 零点校准。
✓ 识别通过 → 自动开门 → 抓拍存证 → 事件记录
✓ 双生物识别 + 机械执行，全程无需人工值守
