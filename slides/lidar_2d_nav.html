问题与动机

Problem & Motivation
1️⃣ 细立柱单帧点云极稀疏
  • Φ2~5cm 立柱通常只有 1~2 个有效击中点；
  • 传统聚类 min_samples≥3 会把它当噪点滤除；
  • 阈值降为 1 又被粉尘反光虚警。
2️⃣ 偏航摆动导致角度漂移
  • 前飞 / 悬停时机体偏航摆动实测达 9°~19°；
  • 机体系下静止立柱的角度大幅跳动；
  • 无法直接做时序追踪。
3️⃣ 临界距离刹车高频振荡
  • 单一阈值下（0.8m 刹 / 0.8m 起步）；
  • 悬停在阈值边缘时测距微噪；
  • 10Hz 刹车-起步剧烈横跳。
✓ 基于 RDK X5 + T265 VIO 的微型无人机
✓ 纯 Python 自研：点云采集 → 坐标系融合 → 状态机联动 → 闭环仿真

坐标系融合 · 从机体系到世界系

Coordinate Fusion
🔄 三级坐标变换（coordinate_fusion.py）
  • ① 雷达极坐标 → 机体系：0° 正前 +X / 90° 正右 −Y / 180° 正后 −X / 270° 正左 +Y；
  • ② 机体系 → 世界系：X_w = X_drone + R(ψ)·[x_b, y_b]，ψ 取 T265 全局偏航角，双向可逆；
  • ③ 世界系 → 机体读数：逆变换用于离线回放与单测断言。
💡 为什么必须转到世界系
  • 机体系：静止立柱角度随机体偏航晃动（±9°~19°），时序关联彻底失效；
  • 世界系：静止立柱绝对坐标恒定，多帧观测天然可叠加；
  • 结论：任何跨帧目标追踪都必须先投影到全局世界系再做。
✓ 纯 Python 标准数学库实现，零第三方依赖
✓ 单测可在任何机器上秒跑

细立柱追踪 · 世界系时序滑窗

Pole Tracker
🔄 核心思路：单帧放宽提取候选，跨帧世界系累加验证
  • ① 单帧候选提取：小半径聚类（eps 0.15m）放宽 min_samples=1，宁可多报不可漏报；
  • ② 世界系投影：候选点结合 T265 实时位姿旋转平移至全局世界坐标系；
  • ③ 滑窗持续验证：最近 6 帧窗口内，同一空间邻域（≤0.2m）命中 ≥3 次才确认；
  • ④ 锁定绝对坐标：确认真实静止立柱，输出世界系物理坐标供避障使用。
❌ 传统单帧聚类
  • min_samples≥3 → 细柱被滤除；
  • min_samples=1 → 粉尘虚警频发。
✅ 世界系时序滑窗
  • 漏检与虚警同时解决：单帧放宽 + 多帧确认，虚警率大幅下降；
  • 把「单帧瞬时判断」升级为「跨帧时空一致性判断」——用时间换信噪比。

避障状态机与迟滞回差

Mission Avoidance FSM
🎮 四状态设计
  • NAVIGATING：巡航导航，持续监测已确认立柱距离；
  • HOVER_AVOIDING：最近立柱 < 0.75m，紧急悬停刹车；
  • BYPASSING：侧向机动脱离危险区，绕开立柱后回航；
  • REACHED_GOAL：抵达目标航点，任务结束。
📐 迟滞回差（Hysteresis Band）
  • 0.75m 进入悬停刹车（POLE_DANGER_DIST_M）；
  • 0.90m 恢复巡航前进（POLE_RESUME_DIST_M）；
  • 触发后不回退：微增至 0.80m 仍保持悬停，直至 >0.90m 或侧向绕行脱离；
  • 双门限严禁同值：阈值相等 = 临界点高频抖动（头号铁律）。
✓ 回差带宽 0.15m，吸收机体晃动与测距微噪
✓ 飞行动作平稳如丝，无临界振荡

铁律与避坑清单

Iron Rules & Pitfalls
📌 波特率必须 460800
  • 镭神 N10P 出厂与飞行工程统一按此配置；
  • 漏配波特率 = 收不到数据，本仓头号坑。
📌 双门限严禁同值
  • 悬停刹车 / 恢复巡航阈值相等 = 临界点高频抖动；
  • 回差带必须保留。
📌 追踪必须转世界系
  • 机体系下立柱随偏航晃动，直接追踪必丢；
  • 先投影再滑窗。
📌 滑窗参数成对调
  • 窗口帧数（6）与命中次数（≥3）联动调整；
  • 单改一个会破坏置信平衡。
✓ 适用：电赛立柱穿越 · 室内低空巡检 · 任何「低线束 2D 雷达 + 细小障碍物」追踪避障
