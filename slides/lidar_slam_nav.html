问题与动机

Problem & Motivation
⚠️ 单一传感器的退化场景
  • 轮式里程计打滑：地毯 / 湿滑地面速度积分漂移；
  • 视觉里程计失效：弱纹理白墙、玻璃反光、光照突变；
  • 纯 IMU 二次积分发散：加速度计噪声随时间平方级累积。
🎯 LIO：激光雷达 + IMU 紧耦合
  • 几何约束不挑环境：点云直接测距，弱纹理 / 暗光都有效；
  • IMU 高频补偿运动：250Hz 预积分补偿雷达帧间畸变；
  • 增量式地图一致约束：新帧对既有地图配准，漂移受抑制。
✓ 宇树 L1：2100 点/帧 @ 10Hz
✓ IMU 250Hz
✓ 双算法互备
✓ 0 云端依赖

算法推演 · FAST-LIO2

Algorithm: FAST-LIO2
🔄 核心流水线
  • IMU 前向传播 → 点云去畸变 → 迭代误差状态卡尔曼滤波（IEKF）→ ikd-Tree 增量地图；
  • 雷达与 IMU 在同一误差状态内迭代，一次更新即收敛。
🌳 ikd-Tree 增量式地图
  • 无需全局重建，新点增量插入 / 动态删除；
  • 最近邻查询复杂度近似 O(logN)，室内小场景实时性最好。
📐 直接法点云配准
  • 点到线 / 点到面残差；
  • 跳过特征提取，弱几何环境也能收敛。
⚡ 为什么选它做主算法
  • 本仓已实调宇树 L1 室内优化参数；
  • Point-LIO 不佳时的备用链路，双算法互为冗余。

算法推演 · Point-LIO 与双算法对比

Algorithm: Point-LIO
🔬 Point-LIO 的差异化设计
  • 点级状态估计：每来一个点即更新，不等整帧累积；
  • 更高融合频率：快速旋转 / 剧烈运动下更平滑；
  • 无显式地图管理：内存占用稳定。
🛠️ 本仓的实战用法
  • 宇树 L1 默认跑 Point-LIO（unilidar_pointlio.launch）；
  • 效果不佳一键切换 FAST-LIO2 备用链路；
  • imu_en 必须开启：关闭 IMU 参与会导致 LIO 退化（踩过坑）。
📊 双算法对比
  • 配准方式：帧级（整帧对地图配准）vs 点级（单点即时融合）；
  • 地图结构：ikd-Tree 增量地图支持建图导出（PCD）vs 滑动状态估计无全局地图；
  • 优势场景：结构化室内建图与一致性 vs 剧烈运动的鲁棒性。

工程落地 · 2D 驱动底层攻坚

Driver Debugging
🐛 Bug 1 · 协议头缺 2 字节
  • 包头硬编码 8 字节，遗漏 2 字节校验和（CS），解析错位；
  • 80%~90% 数据包被当乱码丢弃，点数 0~20 剧烈跳变；
  • 修复：严格 10 字节包头对齐 → 单圈 300+ 点，丢包归零。
🐛 Bug 2 · 采样点字节序颠倒
  • [强度, 距离低, 距离高] 的强度字节被误拼进距离低位，产生大量伪噪点；
  • 修复：分离强度与距离 + 三级抗噪滤波（盲区门限 + 半径 ROR + 角向斑点滤波）。
🐛 Bug 3 · 电机无法软件停转
  • 雷达持续旋转噪音大、寿命损耗；
  • 发现串口停机序列：0xA5 0x00 0xA5 0x65 + Break 条件直接切断电机供电，静音待机。
✓ 单圈有效点：0~20 跳变 → 稳定 300+
✓ 丢包率：80%~90% → ≈0
✓ 电机控制：物理断电 → 串口指令静音

工程落地 · T265 复活记

Reviving T265 on Ubuntu 24.04
① 源码复活
  • Intel 官方 SDK v2.54 已移除 T265 支持；
  • 源码编译 librealsense v2.53.1（最后支持版本）；
  • 开启 -DBUILD_WITH_TM2=ON 跟踪模块后端，Ubuntu 24.04 原生激活。
② 冲击防护
  • 瞬态机械冲击使加速度计量程爆表（Clipping），二次积分发散；
  • 动力学门限拦截非物理单步跳变（Anti-Shock Gating Filter）；
  • 一键零点重标定消除零偏。
③ 坐标系迁移
  • 原生光学右下前系 → REP-103 机器人右手系；
  • 前进 +X / 左移 +Y / 抬升 +Z；
  • T265 看板（:8091）：200Hz 坐标流 · 姿态地平仪 · 一键标定。
✓ 同一套经验可直接迁移到树莓派 / Cubie A7A 等 ARM 平台的 T265 接入

参数调优与避坑清单

Tuning & Pitfalls
⚙️ FAST-LIO2 室内优化（laser_mapping.yaml）
  • 体素网格 0.5 → 0.12m：室内特征锐化约 4 倍；
  • 探测范围 100 → 20m：过滤窗外阳光噪点，降低 CPU 负载；
  • point_filter_num: 1：保留全部采样点；
  • 输出 /Odometry：实时高精度 6-DOF 里程计。
🪤 Point-LIO 实战避坑
  • imu_en: true 勿关：关闭 IMU 参与会导致 LIO 退化；
  • 启动前清共享内存：rm /dev/shm/fastrtps_* 防启动失败；
  • IMU 初始化 20~30s：启动后等自检完成再出数据；
  • 双算法互备：Point-LIO 不佳时切 FAST-LIO2 链路。
